# Rift Circuit browser test build

Built from source commit 5cb32ef in MiszterSoul/RougeLiteRacer.

Visible equipment upgrades, selectable paints and 1/2/4 boosters, themed planet rivals and double-sized bosses.

WASD/arrows: drive. Hold S/Down to brake and reverse. Space: boost (disabled while reversing). R: repair. Escape: pause.

The browser version requires WebGL 2. Font and third-party notices accompany the build.
